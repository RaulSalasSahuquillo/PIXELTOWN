# MESSAGE FROM THE CREATOR

> In case you see this file empty, it means that there is nothing to say/declare about PIXELTOWN or the whole project itself. Otherwise, you are required to read this file before doing anything with the game, since it is a message from the creator and main developer of PIXELTOWN (Raúl Salas Sahuquillo), and means that there might be an issue with the most recent version or extra information that surely will be useful you you.

## Message regarding to v3.2.0. issues.

Hello, I am Raúl Salas Sahuquillo, the creator and main developer of PIXELTOWN. I want to clarify a few things about the recent implementation of pygbag, which was introduced in v3.1.0.

- I am aware that the latest version of PIXELTOWN (v3.2.0) has performance issues in WebAssembly mode. I apologize for that.

- This recent update introduces a more interactive map that makes players feel more connected to the game. However, this requires a significant amount of local processing power, which pygbag cannot currently handle efficiently. As a result, the game suffers from various bugs and performance issues.

- Not everything is bad news, though: the game still works perfectly in its standard Pygame format. However, I am facing a dilemma. I can either continue working on fixing the performance issues gradually, version by version; hand over the WebAssembly project to an experienced community that can independently continue developing the web version; or simply discontinue pygbag support and focus on the Pygame version while working on bringing back the Android version.

- I will make a decision based on how next updates come out. 

Thank you everyone who is interested in the game and the developement and I promise to come up with even greater features and news for the game.
 — Raúl Salas Sahuquillo
